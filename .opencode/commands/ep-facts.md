# S0~S1 · 주제 · 사료 리서치

주제: **$ARGUMENTS**

## 절차

1. **주제 확정.** 인자가 비었으면 `episode-candidates.md`에서 상태 🟢인 후보를 고른다.
   - 🔴 기각 목록은 사유가 확인된 것 — 재검토하지 않는다.
   - **거부 소재**: 동북공정 인접(고구려·발해 귀속), 근현대 정치(해방 이후), 위안부·독도.
   - slug을 정한다(로마자 소문자-하이픈). `episodes/<slug>/`를 만들고
     `docs/EPISODE-STATE-TEMPLATE.md`를 `episodes/<slug>/STATE.md`로 복사한다.

2. **사료 수집** → `episodes/<slug>/facts.md`
   - 출처 우선순위: 우리역사넷(contents.history.go.kr) > 한국민족문화대백과(encykorea.aks.ac.kr) > 조선왕조실록DB(sillok.history.go.kr) > 기타.
   - **주장 하나마다 출처 URL 2개.** 1개뿐인 흥미로운 주장은 "야사/설" 라벨을 붙인다.
   - 항목마다 F1, F2… 번호를 매긴다(뒤 스테이지에서 참조한다).
   - 연도·수치·인명·인과를 분리해 적는다.

3. **훅 후보 3개**를 같이 뽑는다 — 역설 / 반전 / 의외의 수치.

4. `STATE.md`의 S0·S1 체크박스를 채우고 slug·훅 후보를 적는다.

## 주의 (실제로 사고 난 것)

- **한문 원문과 실록 기사 ID는 지어지기 쉽다.** 대본·화면에 들어갈 인용은 **반드시 원문 페이지를 직접 열어 대조**한다. 검색 스니펫만 보고 옮기지 마라. (지뢰 #38)
- **"사료에 없음"이라는 판정도 검증 대상이다.** 없다고 단정하기 전에 다른 검색어로 한 번 더 찾는다. (지뢰 #39)
- **후보 문서에 적힌 '왜'(인과)도 그대로 믿지 마라** — 사료와 정반대인 사례가 있었다. (지뢰 #59)
- 웹 접근이 불가능하면 **추측으로 채우지 말고** 사용자에게 facts.md를 채워 달라고 요청하고 멈춘다.
