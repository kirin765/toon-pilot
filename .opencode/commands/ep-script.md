# S2~S3 · 대본 · 팩트체크

정보량(지정 없으면 중간): **$ARGUMENTS**

## S2. 대본 → `script.txt`

한 줄 = 한 문장. 구조:

```
1행    훅 (0–2s): 결말·역설을 먼저. "○○한 왕이 있었습니다" 형.
       ✗ "오늘은 ~를 알아보겠습니다" 금지.
본문   상황 → 전개 → 반전. 반전은 1개, 그걸 떠받치는 사료를 충분히 깐다.
끝-1행 펀치라인.
끝행   "삼십 초 역사. 다음 편이 궁금하면, 구독."
```

**먼저 facts.md 배분표를 만든다.** 항목(F1, F2…)마다 `내레이션 / 화면만 / 미사용`을 정하고 STATE.md에 적는다.
정보량 '중간'이면 **내레이션 항목이 5개 이상**이어야 한다. 스탬프·num-pop은 내레이션을 보강하는 것이지 대체하지 않는다.

### 청취 가독성 (이게 1순위 — 길이보다 우선)

자막 없이 **처음 듣는 사람이 한 번에 이해하는가**로 판정한다. 두 번 읽어야 풀리는 문장은 귀로는 못 따라간다.

- **한 문장 = 정보 1개.** 쉼표로 정보 2개를 잇지 않는다.
- 명사 앞 수식이 4어절을 넘으면 문장을 쪼갠다.
- 도치·인용 후치 금지 — 자연 어순으로.
- 문장 ≤ 12어절(15 초과 금지). `~습니다` 3연속 금지.
- **숫자는 TTS가 읽을 한글로**: 15만 → 십오만, 1608년 → 천육백팔년. (표시형 변환은 S5에서)
- 길면 압축하지 말고 **문장을 쪼개거나 사료 항목을 통째로 뺀다.**

## 게이트 1 — 대본

```bash
python3 bin/check_script.py --density 중간
```

**exit 0이 될 때까지 고친다.** ✗는 반드시 해소, ⚠는 판단해서 처리하되 무시했으면 이유를 STATE.md에 남긴다.

## S3. 팩트체크 게이트 → `episodes/<slug>/factcheck.md`

1. 대본에서 **모든 사실 주장**(연도·수치·인명·인과)을 뽑아 표로 만든다.
2. 각 주장을 facts.md의 F번호와 1:1로 매핑한다.
3. **매핑되지 않는 주장은 대본에서 삭제**하거나 `/ep-facts`로 돌아가 출처 2개를 확보한다.
4. 표를 `factcheck.md`로 저장한다.
5. 가능하면 `@factcheck-adversary` 서브에이전트에게 적대적 검증을 시킨다 —
   자체 팩트체크는 facts.md **자체의** 오류를 못 잡는다(지뢰 #31).

**S3을 통과하지 않고 S4로 가지 않는다.**
