# S8 · 이중 검수 게이트

slug: **$ARGUMENTS**

## 1. 프레임 추출

훅 + 대표 씬 3개, 총 4장:

```bash
for t in <훅시점> <씬2중반> <씬3중반> <씬4중반>; do
  ffmpeg -y -ss $t -i renders/<slug>.mp4 -frames:v 1 /tmp/frame-$t.png; done
```

## 2. 블라인드 가독성 — `@blind-reviewer` 서브에이전트

프레임 경로만 주고 호출한다. **에피소드 주제·소품 이름·의도를 절대 같이 알려주지 마라.**
알려주는 순간 게이트가 무력해진다. 가능하면 2명(서로 다른 모델)을 돌린다.

작화한 세션이 자기 검증하면 오독을 못 잡는다 — 반드시 분리된 검수자에게 맡긴다.
서브에이전트를 쓸 수 없으면 `docs/BLIND-REVIEW-PROMPT.md`를 사용자에게 주고
**다른 채팅**에 프레임과 함께 붙여넣어 결과를 받아오게 한다.

### 판정

- 통과 기준은 **의도한 이름과 실제 명명이 일치하는가** 하나뿐이다.
- ⚠ **확신도는 통과 근거가 아니다** — 블라인드 벤치 180종 실측에서 오독의 63%가 확신도 '상'이었다.
- ⚠ **검수자의 프레임↔씬 대응과 픽셀 좌표는 믿지 마라**(지뢰 #72). 유효한 것은 "무엇으로 보이는가"뿐이다.
  지적된 위치는 직접 크롭해 확인한 뒤 판정하되, **설명이 틀렸다고 지적 자체를 기각하지 마라**
  (설명은 틀렸는데 지적은 맞았던 사례가 있다).
- 불합격 → 해당 오브젝트를 `docs/ART-RULES.md` §3 시그니처 표 기준으로 재작업 → `/ep-scene <번호>`부터 다시.
- 표에 없는 **새 오독**이면 시그니처 표에 행을 추가한다.

## 3. 고증 체크 — `@gojeung-reviewer` 서브에이전트

같은 프레임으로 중국식·일본식 오독 요소와 시대착오를 검사한다.
지적된 요소는 수정한다. 시대착오면 `facts.md`까지 되돌아간다.

고증 검수는 미술 검수가 못 보는 **렌더 버그도 잡는다**(지뢰 #68 — "문루 지붕을 관통해 솟은 깃대").

## 4. 결과 기록

두 검수 결과와 판정을 STATE.md에 적는다.
**불합격 항목이 남아 있으면 S9로 가지 않는다** — 게이트를 완화하지 않는다.
