# S6 · 씬 저작 루프 — 씬 $ARGUMENTS

**씬 하나만 한다.** 전 씬을 몰아 쓰고 나중에 검수하면 수정 왕복이 커져 "대충 통과"로 기운다(실측).
저작 → 스냅샷 → 11항목 점검 → 통과 → 그다음 씬. 이 순서를 지킨다.

아트 규칙 전문: @docs/ART-RULES.md

## 1. 저작

`scenes.js`의 씬 플랜 표(S6.0)에서 이 씬의 행을 읽고, `scenes.js` 항목 + `index.html` 씬 블록을 쓴다.

- 소품은 **`props-catalog.md`에서 찾아 복사-리컬러-변형이 기본**, 신규 작화는 예외.
- 새로 그릴 때: 실물 구성 요소를 3~6개로 목록화 → 요소당 `<g data-obj>` 하나 → 레퍼런스 트레이스(프리핸드 금지) → `design.md` 팔레트.
- ⚠ **모델은 지침의 하한선까지만 그린다**(지뢰 #16). 요소 목록만 지키면 요소당 프리미티브 1개짜리
  막대그림이 나온다 — 아래 하한을 **숫자로 세서** 채운다.
- 모든 소품에 `data-adj="<씬id>-<이름>"`을 저작 시점에 부여한다(S6.5 튜너 전제).
  소품 내부는 시각적으로 독립된 조각까지 `<g data-obj="키">`로 중첩 그룹핑한다.

### 씬 최소 규격 — 세어서 확인 (전 씬 필수, 아웃트로 제외)

- [ ] **3레이어**: ①환경(하늘 요소 ≥1 또는 지면 디테일) ②주 소품 1개 ③보조 소품/배경 실루엣 ≥1
      · 실내 씬은 **벽 요소 ≥ 2종**(창·문·병풍·족자·서가·선반) + **바닥 디테일 ≥ 1**
- [ ] **주 소품** 렌더 폭 ≥ 380px (또는 높이 ≥ 500px)
- [ ] **프리미티브** 주 소품 ≥ 12개 · `data-obj` 그룹 ≥ 4 · 보조 소품 ≥ 5개
- [ ] **2톤 명암**: 한 변 200px 넘는 면은 단색 금지 — 벽·바닥·하늘 밴드도 예외 없음
- [ ] **배경 대비**: 흑백으로 바꿨을 때 소품 실루엣이 사라지면 불합격

### 지면·스케일

- 지면선 `bottom: 560px` 선언 → 서 있는 모든 것의 하단을 ±100px에 스냅
- 캐릭터 `w 380~440` / `bottom 560~660` / 높이 = `w × 1.2`
- **캐릭터가 기준자다**: 말·소 1.0~1.3 · 단층 한옥 1.5~2.2 · 궁궐 전각 ≥2.2 · 어좌 세트 1.2~1.8 · 손도구 ≤0.5
- 문은 하단이 지면선에 닿고, 창은 하단이 지면선+120~420px
- 애매하면 **크게** 잡는다 — LLM 초안은 체계적으로 작고 낮게 찍힌다(사람이 ×1.8~2.5로 키운 이력)

## 2. 스냅샷

```bash
npx hyperframes snapshot --at <이 씬의 대표시점> --no-end --describe false -o /tmp/snaps
```

대표 시점 = 자막·스탬프·num-pop이 **모두 떠 있는 순간**(대개 `start + dur − 1.0`).

## 3. 프레임 점검 11항목 (S6.4) — 하나라도 걸리면 고치고 재캡처

1. **자막존 겹침** — 소품이 `bottom 380px` + 2줄(~200px) 영역에 걸리는가 → `bottom ≥ 560px`
2. **스탬프·num-pop ↔ 캐릭터 겹침** → 반대편 빈 구역으로
3. **색 동화** — ①먼저 **완전 동색**인지 본다(동색이면 소품이 통째로 사라지고 부속만 뜬다, 지뢰 #70) ②그다음 명도 차
4. **머리 뒤 원형 소품(해·달) 금지** — 후광/모자로 오독
5. **3초 명명 테스트** — 새 소품 이름이 3초 안에 나오는가. 안 나오면 장식 추가 대신 **시그니처 실루엣 1개**를 강화
6. **씬 최소 규격 재검** — 위 5항목을 프레임 위에서 다시 센다. 빈 단색 영역이 화면 절반을 넘으면 레이어 누락
7. **스케일 새니티** — 말<캐릭터, 건물≤캐릭터, 어좌<캐릭터는 즉시 불합격
8. **부양 검사** — 지면 접점 없이 뜬 오브젝트는 원경 실루엣 외 0개
9. **벽 요소 앵커** — 문 하단이 지면선에 닿는가, 창 하단이 지면선+420px 이하인가
10. **장소 판독** — 프레임만 보고 씬 플랜 표의 '장소'가 맞혀지는가 (궁이면 전각·월대·박석 중 ≥1)
11. **배경 중복** — 직전 씬과 같으면: 같은 장소가 맞는지, 4연속째가 아닌지, 눈에 보이는 변화 ≥1이 있는지

**"그림체가 미니멀해서 괜찮다"로 면제되는 항목은 없다** — 미니멀함은 팔레트와 셰이프 언어에서 오는 것이지
요소 개수 부족에서 오는 게 아니다.
