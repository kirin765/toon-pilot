# 블라인드 검수 프롬프트 (S8 게이트)

작화한 세션이 자기 검증하면 오독을 못 잡는다. 아래 프롬프트를 **컨텍스트가 전혀 없는 곳**
(새 채팅 / 다른 모델 / 서브에이전트 / 사람)에 프레임 이미지와 함께 그대로 붙여넣는다.

에피소드 주제·소품 이름·의도를 절대 같이 알려주지 않는다. 알려주는 순간 게이트가 무력해진다.

---

## 1) 블라인드 readability — 그대로 복사

```
이 이미지들에 보이는 오브젝트를 전부 명명해 주세요.

규칙:
- 화면 안의 글자(자막·도장·라벨)는 읽지 말고 무시하세요. 글자를 근거로 답하지 마세요.
- 각 오브젝트마다: (1) 무엇으로 보이는지 (2) 대략 어디에 있는지 (3) 확신도(상/중/하)
- 모르겠으면 "불명"이라고 쓰세요. 추측해서 그럴듯한 이름을 붙이지 마세요.
- 화면 전체가 "어떤 장소·어떤 상황"으로 보이는지 한 줄로 덧붙여 주세요.

설명·해석·칭찬은 필요 없습니다. 목록만 주세요.
```

**판정 방법**

- 통과 기준은 **의도한 이름과 실제 명명이 일치하는가** 하나뿐이다.
- **확신도는 통과 근거가 아니다** — 블라인드 벤치 180종 실측에서 오독의 63%가 확신도 '상'이었다.
- 검수자의 **프레임↔씬 대응과 픽셀 좌표는 신뢰하지 않는다**(지뢰 #72). 지적된 위치는 직접 크롭해 확인한 뒤 판정하되, **설명이 틀렸다고 지적 자체를 기각하지 않는다.**
- 검수자를 2명(가능하면 다른 모델) 두면 좌표·씬 서술이 어긋나도 명명은 교차 확인된다.
- 불합격 → 해당 오브젝트를 `docs/ART-RULES.md` §3 시그니처 표 기준으로 재작업. 표에 없는 새 오독이면 **표에 행을 추가**한다.

**게이트 기대치 (모델 급 차이)**

- 물리 소품·야외 행위 씬(낚시·대장간·파발) → 저가 모델(haiku급)까지 실루엣 판독 기대 가능.
- 사회적 의례 씬(어전·사사·시험)의 **'상황' 판독은 저가 모델에게 기대하지 않는다** — 자막·스탬프가 상황을 전달한다.
- 저가 모델 게이트의 합격 기준은 "다른 물건으로의 **적극 오독**(모루→팬, 어전→무대, 측우기→나무통)이 없을 것"이지, 고유 명칭 명명이 아니다.

## 2) 고증 체크 — 그대로 복사

```
이 이미지들은 한국사(조선 시대)를 다루는 짧은 영상의 한 장면입니다.

중국식 또는 일본식으로 오독될 수 있는 복식·건축·기물 요소가 있는지만 지적해 주세요.
예: 변발, 기모노식 깃(좌임), 중국식 처마 곡선, 일본 지붕의 가로 줄무늬,
    쇼지(균등 격자 창), 의자 좌식 가구, 동심원 양궁 표적 등.

각 지적마다: 무엇이 / 어디에 / 왜 그렇게 보이는지 한 줄씩.
문제가 없으면 "없음"이라고 쓰세요. 좋은 점은 쓰지 마세요.
```

**판정 방법**

- 지적된 요소는 수정한다. 컷아웃 그림체가 고증 기대치를 낮춰 주지만 **명백한 타국 문법은 악플 트리거**다.
- 고증 검수는 미술 검수가 못 보는 **렌더 버그도 잡는다**(지뢰 #68 — "문루 지붕을 관통해 솟은 깃대").
- 시대착오(그 시대에 없던 물건)도 여기서 잡히면 `facts.md`로 되돌아간다.
