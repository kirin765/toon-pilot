| F1 | 측우기 = **규격을 표준화한 세계 최초의 우량계**('the first standardized rain gauge', 영문 위키). ⚠ "장치 자체 세계 최초"는 오류 — 중국 진구소 천지분(1247, 지방 관청 설치)이 194년 앞서고 인도 아르타샤스트라(BC 4C)·유대 미쉬나도 강우 측정 선례. **방어선 = "표준/규격 통일" 한정 필수**. 1441년(세종 23) 제작 | 영문 위키 Rain gauge · Tianchi basin · 위키 · 우리역사넷 |
| F2 | 서양 최초 우량계(이탈리아 베네데토 카스텔리, 1639)보다 **198년(약 200년) 앞섬** | 위키백과 측우기 · 서울경제 · 나무위키 |
| F3 | **발명(고안)자는 장영실이 아니라 세자(뒤의 문종, 1414~1452)** — 세종실록이 명기 | 경향 이기환 Hi-story · 우리역사넷 · YTN · 더리포트 |
| F4 | 세종실록 세종 23년(1441) 4월 기록: "근년 이래로 **세자가 가뭄을 근심하여**, 비가 올 때마다 땅을 파서 젖어든 깊이를 재보았으나 정확하지 못하므로, **구리를 부어 그릇을 만들어 궁중에 두고** 고인 빗물의 푼수를 실험했다" | 경향 이기환 · 우리역사넷 |
| F5 | 측정 이전 방식 = 입토심(入土深): 비 온 뒤 땅을 파 젖어든 깊이로 강우 추정 → 흙·지형 따라 제각각이라 부정확. 측우기가 이를 표준 그릇 측정으로 대체 | 경향 이기환 · 우리역사넷 |
| F6 | 1441년 8월 서운관(書雲觀)에 설치, 규격 확정: 쇠, 길이 2척·지름 8촌. 1442년 개량 규격: 길이 1척 5촌·지름 7촌(약 32cm×15cm), 지방 관청에도 배포 | 우리역사넷 · 위키 |
| F7 | 실록 규격 원문(세종 24년 1442, 5.8): "京中則鑄鐵爲器, 名曰測雨器, 長一尺五寸、徑七寸"(서울에선 쇠를 부어 그릇을 만들어 측우기라 이름하니, 길이 한 자 다섯 치, 지름 일곱 치) | 위키(실록 인용) · 경향 이기환 |
| F8 | 발명 동기 = "民惟邦本 食爲民天(백성은 나라의 근본, 먹는 것은 백성의 하늘)" — 농사·가뭄 대비. 왕들이 측우 기록으로 풍흉 예측 | 경향 이기환 |
| F9 | (아이러니) 측우기 규격이 공식 반포된 1442년 5.8 무렵, 통념상 발명자로 아는 **장영실은 안여 파손으로 국문받고 곤장형(5.3 결정)** 당하며 역사에서 사라지는 중이었다 | 경향 이기환 · EP.1 facts.md |
| F10 | (배경) '측우기=장영실' 통념의 기원 = **해방 후 1960~70년대 한국 위인전·과학교과서의 장영실 신화화**(박정희 정권 위인 성역화). ⚠ 와다 유지(1917) 기원설은 오류 — 와다는 실록 근거로 세종/문종 업적으로 정확히 서술(2차 factcheck A5). **대본은 통념 '기원'을 언급하지 않고 "흔히 장영실로 안다"는 존재 사실만 진술 → 안전** | 동아일보(2차 factcheck) · 전상운·신동원 |
| F11 | 현존 유일 실물 = 금영측우기(1837 제작, 공주 충청감영). **국보 제329호(2020.2 보물 제561호에서 승격)**, 국립기상박물관 소장. 1915 일본 반출 → 1971 반환. (대본 미언급) | 국가유산청(2차 factcheck A8) · 우리역사넷 |

## ⚠️ 적대적 검증 대비 (오독·과장 주의선)

| 위험 주장 | 안전선 |
|---|---|
| "장영실은 측우기와 전혀 무관" | ❌ 단정 금지. 일부 2차자료는 1441.8 서운관 제작 실무에 장영실 관여 언급. **안전선: 실록은 '고안·발명자'로 세자를 명기했고, 장영실을 측우기 발명자로 적은 실록 기록은 없다** = 통념(장영실)이 근거 없음 |
| "세자가 혼자 다 만들었다" | 한글 창제 뉘앙스와 동일 — 실록은 세자의 '고안/발상'을 명기. 물리적 제작은 서운관·공조 장인. "실록엔 세자가 고안했다고 적혀 있다"가 정확 |
| "세계 최초" 단정 | F1·F2는 '통일된/표준화된' 우량계 세계 최초로 한정하면 안전(서양 카스텔리 1639 대비 198년). "표준" 수식 유지 |

## 훅 후보
1. (채택) "세계 최초의 그 발명품, 만든 사람은 과학자가 아니었다" — 세계 최초(수치 충격) + 발명자 반전(장영실→세자)
2. "우리가 장영실의 것으로 아는 발명, 실록엔 다른 이름이 적혀 있다" — EP.1 시리즈 연결
3. "빗물의 깊이를 잰 소년이, 다음 왕이 됐다" — 인물 서사
