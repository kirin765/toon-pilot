## 제작 메모 (다음 에피소드 참고용)
- **TTS 발음 이슈**: edge-tts ko-KR-InJoonNeural 보이스가 "금오"(금오산/금오신화)를 일관되게 "금호"로 오발음(여러 문맥·다른 보이스로도 재현, 표기 변경으로도 해결 안 됨). 대사에서 "금오"를 피하고 "경주 남산"(동일 지명)으로 우회, 「금오신화」 타이틀은 화면 스탬프로만 노출. 유사 지명/고유명사 등장 시 TTS 재생성 후 반드시 재확인.
- **스탬프 애니메이션**: `scale: 2.x → 1` (큰 상태에서 슬램) 방식은 GSAP `fromTo`의 immediateRender가 확대된 pre-state를 만들어 씬 컨테이너의 scrollWidth를 부풀리고 `clipped_text` 린트 에러를 유발함. 반드시 `scale: 0 → 1`(back.out 이징)로 작성할 것 — PROJECT-NOTES 지뢰 #2와 동일 계열 이슈.
- **배경 풀블리드 장식**(캔버스보다 넓은 산/hill)은 `overflow:hidden` 래퍼(`data-layout-ignore`)로 감싸지 않으면 부모 씬의 scrollWidth를 부풀려 동일한 `clipped_text` 에러 유발.
- **고증 검수 실증**: 블라인드 검수는 통과했으나 고증 검수에서 무량사 탑(pagoda) prop이 빨간 채색+금색 상륜부라 "일본식 오중탑"으로 오독될 위험 발견 → 무채색 화강암 톤(#9a8f7c 계열)으로 재채색, 금색 장식 제거해 한국 석탑으로 수정. **교훈: 탑·건축물은 채색(특히 빨강+금)이 붓칠/재질을 암시해 국적 오독을 유발할 수 있음 — 한국 석탑류는 무채색 석재 톤 유지.**
- chrome-headless-shell 최초 다운로드 시 `hyperframes render`의 자체 zip 추출 로직이 멈춘 것처럼 느려질 수 있음(관찰: 25분+ 정체, CPU 사용량 낮음) — `unzip -q`로 수동 추출 후 재시도하면 정상 진행됨.
- **사용자 1차 피드백 반영(2026-07-10)**:
  1. 자막 숫자 표시형 변환 누락 — "다섯 살"→"5살", "사흘"→"3일"로 CAPTION_GROUPS(및 WORDS 참고용) 수정. 나이·기간처럼 작은 수여도 사용자가 요구하면 변환할 것(S5 후편집 규칙을 임의로 생략하지 말 것).
  2. **승려가 된 뒤에도 갓을 계속 쓰고 있던 문제** — `characters.js`에 `cfg.noHat` 옵션 추가(militia variant 한정, 갓 대신 맨머리+옅은 음영). `wrapTf`의 CHAR_TUNING 오프셋은 갓 형태에 맞춰진 값이라 민머리에는 적용하지 않고 우회(`cfg.noHat ? hat : wrapTf(...)`). scenes.js에서 승려 이후 씬(s4~s6)에 `noHat:true` 지정.
  3. **갓 위치 어긋남** — `char-tuning.js`의 militia.hat이 `y:-20, s:1.3`으로 과도하게 커지고 위로 떠 있었음(피벗 계산상 크라운 상단이 뷰박스 밖으로 나갈 정도). `y:-4, s:1.05`로 축소·하향 조정.
  4. **배경이 비어 보인다는 지적** — s2(궁궐)에 익랑 2채+월대+홍살문+잡상 추가해 단일 기와집이 아닌 궁궐 단지로 확장, s3(통곡)에 성곽 실루엣+먹구름+빗줄기 추가, s4(분신)에 방 내부 암시(창문)+화문석+흩어진 책장+연기+잉걸불 추가, s6(무량사)에 법당 건물+박석 마당 추가.
  5. **배경 요소 삽입 시 자막 안전존 겹침 주의** — 처음 만든 s5 hermitage(경주 남산 암자)가 `bottom:480px`로 배치되어 자막 pill(`bottom:380px` 기준, 2줄이면 높이 ~200px)에 거의 완전히 가려짐 → 실제 렌더 프레임을 잘라보기 전까지 발견 못함(정적 인스펙터 경고 없음, 시각적 문제라 프레임 캡처로만 잡힘). **교훈: 화면 하단 1/3에 배경 소품을 놓을 때는 반드시 렌더 프레임에서 자막이 활성화된 순간을 확인할 것.** `bottom:640px`로 상향 조정 후 해결.
  6. GSAP `repeat:-1`(무한 반복)은 린트 에러(`gsap_infinite_repeat`) — 결정론적 프레임 캡처와 호환 안 됨. 연기·불씨처럼 반복 애니메이션이 필요하면 `Math.floor(씬잔여시간/사이클시간)-1`로 유한 repeat 계산.
  7. 기존 스탬프 애니메이션(`path:last-child` 같은 위치 기반 선택자)에 새 SVG 요소를 추가하면 선택자가 의도치 않은 다른 요소를 가리킬 수 있음 — s4에 연기 path를 추가했더니 불꽃 깜빡임 애니메이션이 연기를 대상으로 바뀌는 버그 발생. **교훈: 위치 기반 선택자(`:last-child`, `:nth-child`) 대신 명시적 클래스명을 쓸 것.**
