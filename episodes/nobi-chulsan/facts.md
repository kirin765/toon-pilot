# facts.md — EP.18 세종의 관노비(官婢) 출산휴가

주제: 세종이 공노비(관비) 산모·남편에게 준 출산휴가 3단계 변천.
검증: 리서치 에이전트(gov sillok 페치) + **본 세션이 위키문헌(ko.wikisource) raw 위키텍스트로 3건 원문 전량 글자단위 독립 재확인**. 지뢰 #38(서브에이전트 한문 신뢰 금지) 준수 — 원문은 두 독립 1차 미러에서 일치.
⚠ gov sillok(sillok.history.go.kr)은 이 환경에서 연결 거부(해외 IP 차단). 기사 ID는 에이전트 보고값(교정본)이며, 원문 대조는 위키문헌으로 완료.

## 검증된 사실 (주장마다 출처 2개)

### F1. 1426 산후 100일 — 원제도 7일에서 확대
- **세종 8년(1426) 4월 17일**, 형조에 내린 전지(왕명). 기사 ID `kda_10804017_004`(에이전트 교정 — 추정 `_001`은 경연 기사였음).
- 원문: **「傳旨刑曹, 京外公處婢子産兒後, 給暇百日, 以爲恒式。」** (위키문헌 verbatim 확인)
- 국역: 형조에 전지 — "경외 공처(관청)의 비자가 아이를 낳으면 100일 휴가를 주고, 항식(상시 규정)으로 삼으라."
- 출처: 실록 https://sillok.history.go.kr/id/kda_10804017_004 · 위키문헌 https://ko.wikisource.org/wiki/조선왕조실록/세종장헌대왕실록/8년

### F2. 원제도 = 산후 7일 (세종 이전)
- 1430 기사에서 세종이 회고: **「古者公處奴婢, 必令産兒七日後立役」** — 옛적엔 관노비가 아이 낳고 7일 뒤 복무.
- 근거는 F3 기사(별도 초기 기사 아님). 출처: F3와 동일.

### F3. 1430 산전 한 달(一朔) 추가 → 도합 약 130일
- **세종 12년(1430) 10월 19일**, 세종이 대언(승지)들에게 직접 발의. 기사 ID `kda_11210019_006`(추정 `_001`은 상참 기사였음).
- 원문(위키문헌 verbatim): **「古者公處奴婢, 必令産兒七日後立役者, 矜其棄兒立役, 以傷小兒也。曾命加給百日, 然臨産而立役身勞, 則未及其家而産者, 或有之, 若臨産月, 除役一朔, 何如? 彼雖欺罔, 豈過一月乎? 其令詳定所幷立此法。」**
- 국역 요지: "옛적엔 7일 뒤 복무시켰는데 아기가 상할까 염려했다. 앞서 100일을 더 줬으나, 산기에 임박해 일하다 지쳐 집에 가기 전 낳는 일이 있으니, 산달엔 한 달 복무를 면하면 어떤가. 속인들 한 달을 넘기겠나. 상정소에 법으로 세우라."
- **산전 一朔(≈29~30일) + 산후 100일 = 약 130일.** ⚠ '130'은 산전+산후 합산치이며 실록이 그 숫자로 적은 것은 아니다.
- 출처: 실록 https://sillok.history.go.kr/id/kda_11210019_006 · 위키문헌 12년 페이지 · 경향(이기환) https://www.khan.co.kr/article/201812200946001

### F4. 1434 남편(奴)에게도 30일
- **세종 16년(1434) 4월 26일**, 형조에 내린 전교(왕명). 기사 ID `kda_11604026_003`(추정 `_001`은 가뭄 기사였음).
- 원문(위키문헌 verbatim): **「敎刑曹: 京外婢子孕兒臨産朔與産後百日內, 勿令役使, 已曾立法。其夫全不給暇, 仍令役使, 不得救護, 非徒有乖於夫婦相救之意, 因此或致隕命, 誠爲可恤。自今有役人之妻産兒, 則其夫滿三十日後役使。」**
- 국역 요지: "산달과 산후 100일엔 비자를 사역시키지 말라 함은 이미 법으로 세웠다. 그런데 남편에겐 휴가를 전혀 주지 않아 산모를 구호 못하니, 부부가 서로 돕는 뜻에 어긋날 뿐 아니라 이 때문에 목숨을 잃는 일까지 있어 진실로 가엾다. 이제부터 그 남편도 만 30일 뒤 복무시키라."
- 이 기사가 여성 휴가 구조(산달+산후 100일)를 스스로 재요약 → F1·F3 결합을 실록이 확증.
- 출처: 실록 https://sillok.history.go.kr/id/kda_11604026_003 · 위키문헌 16년 페이지 · 경향(이기환) 동일

### F5. 대상 = 공노비(관비) 한정
- 세 기사 모두 **公處婢子 / 京外婢子** 명시 = 관청 소속 여종(공노비). **사노비(개인 소유)는 대상 아님.**

### F6. 주체 = 세종의 직접 왕명
- 세 건 모두 傳旨 / 敎 / 上謂…曰 = 임금의 하교·발의. 신하 건의 재가가 아니다.

### F7. 동기 (원문상 인도적·휼민 수사)
- 傷小兒(아기가 상함), 未及其家而産(집에 가기 전 출산), 夫婦相救之意, **因此或致隕命 誠爲可恤(목숨을 잃기까지 하니 가엾다)** — 세종 본인의 발언으로 원문 실재.

## 안전선 (S3·S8 이월 제약)
1. **대상 한정**: "조선의 모든 여성/모든 노비"로 일반화 금지. 공노비(관비) 한정 명시.
2. **복지 낭만화 금지**: 재산관리가 '목적'이라는 논리는 **원문에 없다** — 그렇게 단정 금지. 다만 수혜자=국가 소유 노비, 사노비 미확대라는 **사실상의 경계**는 반전으로 쓸 수 있다(펀치라인). '근대적·보편적 복지'로 읽으면 오독.
3. **숫자 정밀**: 산후 100일(百日 정확), 남편 30일(滿三十日 정확), 산전 一朔(한 달 ≈30일 근사), 총 130일=합산치.
4. **주체**: 세종 직접 왕명 — "신하가 건의" 서술 금지.

## 미검증 (지어내지 말 것 — 대본·화면 사용 금지)
- "당시 관료가 비판했으나 세종이 강행" — 세 원문에 **없음**. 2차 스니펫에만 등장. 사용 금지.
- 현대 수치 대비("2016년 남성 출산휴가 5일" 등)는 2차 언론 프레임 — 대본에 넣지 않음(비교 없이 조선 사실만).

## 훅 후보 3개
1. **[수치·신분 반전]** "조선의 여자 노비에게 백서른 날짜리 출산휴가가 있었다." (F1+F3, 예고 이행 "산모 백서른 날")
2. **[동기 반전]** "출산 이레 만에 복귀시켰더니 아기가 상하고 산모가 길에서 아이를 낳더라 — 그래서 세종이 늘렸다." (F2+F3+F7)
3. **[남편 휴가]** "1434년 조선, 노비 '남편'에게도 출산휴가 30일." (F4, 예고 "남편 서른 날")

→ 채택: 1을 훅(예고 이행), 2·3을 본문 전개, 안전선2를 펀치라인 반전.
