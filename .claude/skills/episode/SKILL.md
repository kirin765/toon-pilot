# 삼십초 역사 — 원커맨드 에피소드

**이 스킬은 래퍼다. 실제 파이프라인은 저장소 안에 있다.**
모델·하네스와 무관하게 같은 절차를 밟게 하려고 문서를 repo로 옮겼다 — 스킬과 문서가 갈라지지 않도록
여기에는 절차를 복제하지 않는다.

## 지금 할 일

1. **`AGENTS.md`를 읽는다** — 프로젝트 정체성·아키텍처·명령·하드 규칙.
2. **`docs/EPISODE-PIPELINE.md`를 읽고 그대로 실행한다** — S0~S9 전 스테이지와 게이트.
3. S6(연출)에 진입할 때 **`docs/ART-RULES.md`**를 연다.
4. S8(검수)에서 **`docs/BLIND-REVIEW-PROMPT.md`**를 컨텍스트 없는 서브에이전트에게 그대로 준다.
5. Claude Code 전용 도구 매핑(웹 검색·서브에이전트·Chrome·텔레그램)은 **`CLAUDE.md`**에 있다.

## 이 스킬이 추가로 보장하는 것

- 스테이지를 건너뛰지 않는다. 특히 **S3(팩트체크) · S6.4(프레임 점검) · S6.5(인간 레이아웃 조정) · S8(블라인드 검수)** 넷은 생략 대상이 아니다.
- 게이트 스크립트가 FAIL이면 다음 스테이지로 넘어가지 않는다:
  ```bash
  python3 bin/check_script.py --density 중간   # S2 이후
  node bin/check_composition.mjs               # S6 이후
  npm run check                                # 렌더 직전
  ```
- S6.5에서 사용자 조정을 기다릴 때, 그리고 최종 완성 시 텔레그램 알림을 보낸다.
- 능력이 없어 건너뛴 게이트가 있으면 **최종 보고에 명시**한다.
