# bench/ — 지침 벤치 하네스

sonnet(A)이 지침만으로 씬을 만들고, 무맥락 판독자(A': sonnet 또는 haiku)가 블라인드 명명, B(고성능 모델)가 브리프 타깃과 대조 채점하는 지침 개선 루프의 기록.

## 평가 프로토콜 (과적합 방지 — 2026-07-12 확립)

1. **두 지표를 구분해서 보고한다.**
   - **첫 시도 점수(first-try)** = 신규 브리프에 대한 최초 생성물의 점수 → 일반화 추정치. (실측: sonnet A' ~91% it2, haiku A' ~70% it4)
   - **수정 후 점수(post-fix)** = 같은 씬을 고쳐서 재판독한 점수 → "규칙으로 고칠 수 있음"의 증명일 뿐, 일반화 증거가 아니다. (it6 81.8%는 이쪽)
2. **브리프는 매 반복 신규로 낸다.** 채점된 씬을 지침 "검증"에 재사용하지 않는다(수정-재판독은 규칙의 처방 효과 확인용으로만).
3. **시그니처 표의 성격**: 씬 단위가 아닌 사물 단위 일반화 — 표는 벤치를 "암기"하는 게 맞고, 그것이 설계다(회귀 테스트 누적 구조). 표에 오른 사물은 재실패 이력 0. 표 밖 신규 사물의 첫 시도 기대치는 haiku 기준 ~70%이며, 실전에서는 S6.4/S8 게이트가 이를 잡아 표에 행을 추가한다.
4. **홀드아웃 검증** = 다음 실전 에피소드를 저가 모델로 처음부터 제작했을 때의 첫 시도 게이트 통과율. 벤치가 본 적 없는 대본·소재가 진짜 테스트다.

## 기록
- it1~it2: A'=sonnet. 78.3% → 90.9%(첫 시도, 목표 달성).
- it3~it6: A'=haiku(보수 게이트). 65% → 70%(첫 시도) → 59%(자산 재사용 함정) → 81.8%(수정 후).
- 각 반복의 브리프/채점/교훈: `itN-briefs.md`, `itN-results.md`. 씬 원본: `itN-sM.html` + PNG.
